About this kit

  1. Nothing leaves this box. The model, the library and the search all run on this machine.
  2. Field Notes is a small AI. It can be confidently wrong, so every answer shows its sources. Check them.
  3. The library is a slice of Simple English Wikipedia. If it isn't in the pack, the model shouldn't know it.
  4. In an emergency, call for help first. This kit is a backup, not a doctor.
